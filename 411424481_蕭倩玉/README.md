## 💡 核心思考構想與資料結構設計
本系統旨在解決車輛快速檢索與滿位時的排隊調度問題，主要運用了以下資料結構：
1. **Array / List (陣列)**：模擬實體停車場的車位狀態，直觀顯示每個車位是空車位或已被佔用。
2. **Hash Table / Dictionary (雜湊表)**：儲存「目前停放中的車輛」，Key 為車牌、Value 為車位編號，讓車輛查詢與離場結帳的複雜度達到 $O(1)$。
3. **Queue (佇列 - FIFO)**：當停車場滿位時，後續車輛依先進先出原則進入等待佇列排隊。
